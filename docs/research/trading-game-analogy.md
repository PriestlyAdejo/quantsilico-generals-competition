# Trading-game analogy

This note maps Generals concepts to trading language for QuantSilico research
intuition. It is an analogy, not a claim that markets equal the game.

## Mappings

| Generals | Trading analogy |
|----------|-----------------|
| army | deployable risk capital |
| general | solvency / survival constraint |
| land | income-producing asset base |
| castle | capital expenditure and carry |
| half move | partial position sizing |
| pass | literal abstention |
| friendly collection | rebalancing |
| defence | hedging |
| fog | latent market state |
| combat loss | transaction cost and adverse selection |
| random maps | unseen regimes |
| faults | operational risk |

## Where the analogy fails

- The game is two-player and close to zero-sum; markets are many-agent and non-stationary.
- The game has known transition rules; markets do not.
- Passivity has a hard-horizon cost in the game; cash can remain valid for longer in trading.

## Usage rule

Use the analogy to generate hypotheses and naming. Validate every claim against
the official engine rules and logged experiments. Do not invent results.
