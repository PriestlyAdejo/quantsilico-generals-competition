# Glossary

- **candidate** — executable policy id under evaluation
- **opponent** — opposing policy in a match or suite
- **evaluation suite** — named set of seeds/maps/rules (e.g. DEVELOPMENT)
- **seed / paired seeds** — RNG controls for deterministic matches
- **train / validation / promotion holdout** — data splits; holdout must stay untouched
- **W/D/L** — wins / draws / losses
- **score rate** — mean match score
- **discovery** — fraction of games where the enemy general is found
- **conversion** — win rate among discovered games
- **terminal turn** — turn when the match ended
- **p50 / p95 / p99** — latency percentiles
- **behavioural cloning (BC)** — imitation initialisation
- **PPO** — Proximal Policy Optimisation
- **PFSP** — Prioritised Fictitious Self-Play
- **PSRO** — Policy Space Response Oracles
- **population / payoff matrix / meta-strategy** — multi-agent evaluation artefacts
- **checkpoint / champion / challenger / lifecycle / compatibility** — model registry terms
- **provenance** — DEMO / imported evidence / portal observation / manual
- **current gate vs historical observation** — live vs upload-time
- **Phase 9Q** — internal id for the Candidate Qualification workflow
