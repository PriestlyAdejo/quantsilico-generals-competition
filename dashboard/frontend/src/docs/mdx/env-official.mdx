# Environment Lab official sessions

Official mode uses the pinned Generals environment.

- Max concurrent sessions: 2
- Default TTL: 15 minutes (max 60)
- Max actions: 5,000
- Session metadata under `var/dashboard/env_sessions/` (not committed)

Create / reset / step / legal-actions / list / close are available when the capability is enabled.

When the session limit is reached, close an existing session from the Environment Lab side panel before starting another. Closing the browser does not always free a live session immediately — use **Close** on the listed session.
